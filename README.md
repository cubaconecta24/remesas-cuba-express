# Remesas Cuba Express

Sitio web estático e informativo para GitHub Pages. El formulario prepara una consulta y abre WhatsApp; no procesa pagos ni transferencias.

## Archivos
- `index.html`: contenido de la página.
- `styles.css`: diseño adaptable a móviles.
- `script.js`: formulario y enlace de WhatsApp.
- `README.md`: estas instrucciones.

## Datos configurados
- Nombre comercial: Remesas Cuba Express.
- WhatsApp: +53 58890666.
- Atención de mensajes: disponible 24/7; las respuestas pueden no ser inmediatas.
- Alcance actual: consultas e información general solamente.

## Publicar o actualizar en GitHub Pages
1. Abre el repositorio `remesas-cuba-express`.
2. Sustituye los archivos existentes por los cuatro archivos de esta carpeta (sube los archivos, no la carpeta contenedora).
3. Confirma los cambios con **Commit changes**.
4. En **Settings → Pages**, comprueba que esté seleccionado **Deploy from a branch**, la rama `main` y la carpeta `/(root)`.
5. Espera a que GitHub Pages complete la publicación. La dirección aparecerá en **Settings → Pages**.

## Importante: alcance y cumplimiento
Esta versión solo permite enviar consultas por WhatsApp. No recibe dinero, no ejecuta transferencias, no cambia divisas, no garantiza métodos de entrega ni confirma que exista un proveedor disponible.

Antes de anunciar, intermediar, ofrecer o ejecutar remesas, verifica con asesoría jurídica especializada los requisitos y autorizaciones aplicables en Cuba y en cada país desde el que se captarían clientes, así como las normas sobre servicios financieros, pagos, sanciones y protección de datos. No añadas tarifas, promesas de entrega o métodos de pago hasta que estén legalmente verificados.

## Privacidad
El formulario no guarda los datos en esta web; prepara un mensaje que el visitante puede revisar y enviar por WhatsApp. Evita solicitar datos bancarios, contraseñas o documentos de identidad mediante este formulario. Añade una política de privacidad revisada legalmente antes de realizar campañas o recoger datos personales de forma sistemática.
