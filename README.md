# Remesas Cuba Express

Sitio web estático inicial para GitHub Pages.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño adaptable a móviles.
- `script.js`: formulario que prepara una solicitud de WhatsApp.

## Antes de publicar
1. Abre `script.js`.
2. Sustituye `WHATSAPP_NUMBER = ""` por el número oficial en formato internacional, sin `+`, espacios ni guiones.
3. Revisa el texto legal y las condiciones del servicio con asesoramiento adecuado.
4. No añadas funciones de cobro ni prometas transferencias hasta contar con proveedor autorizado y cumplir los requisitos legales aplicables.

## Publicar gratis con GitHub Pages
1. Crea un repositorio público llamado `remesas-cuba-express`.
2. Sube todos estos archivos a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona `main` y `/ (root)`, y guarda.
6. GitHub mostrará la dirección pública de tu web cuando termine el despliegue.
