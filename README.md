# Remesas Cuba Express

Sitio web estático e informativo para GitHub Pages. El formulario prepara una consulta y abre WhatsApp; no procesa pagos ni transferencias.

## IMPORTANTE: los cinco archivos de la web van juntos en la raíz

Este paquete está preparado para que NO tengas que crear ni subir una carpeta `assets`. Extrae el ZIP y verás estos archivos juntos:

- `index.html`
- `styles.css`
- `script.js`
- `logo-remesas-cuba-express.png`
- `README.md`

El archivo de imagen debe conservar exactamente este nombre, incluidas las letras minúsculas: `logo-remesas-cuba-express.png`.

## Cómo actualizar el repositorio desde el móvil

1. Descomprime este ZIP en el teléfono.
2. Abre el repositorio `sanchezjuanantonio963-pixel/remesas-cuba-express` en GitHub.
3. Entra en **Add file → Upload files**.
4. Selecciona los cinco archivos indicados arriba desde la carpeta donde descomprimiste el ZIP. Selecciona los archivos, no una carpeta que los contenga.
5. Comprueba que quedan al mismo nivel que el `index.html` del repositorio, no dentro de una carpeta nueva.
6. Pulsa **Commit changes** para guardar la actualización en la rama `main`.

Si GitHub pregunta cómo guardar el cambio, confirma el commit en `main`. No borres el repositorio ni cambies la configuración de Pages.

## Comprobación de GitHub Pages

En **Settings → Pages**, la fuente debe ser **Deploy from a branch**, la rama `main` y la carpeta `/(root)`. El archivo `index.html` y el logotipo deben estar en esa raíz. GitHub Pages publica el contenido de la carpeta seleccionada y el nombre `index.html` distingue mayúsculas de minúsculas.

Página: https://sanchezjuanantonio963-pixel.github.io/remesas-cuba-express/

Después del commit, revisa **Actions** y espera a que la publicación de Pages termine correctamente. En el móvil, recarga la página; si aparece la versión anterior, abre el enlace en una pestaña privada o vuelve a cargarlo más tarde.

## Alcance, cumplimiento y privacidad

Esta web actualmente solo permite enviar consultas por WhatsApp. No recibe dinero, no ejecuta transferencias, no cambia divisas, no garantiza métodos de entrega ni confirma que exista un proveedor disponible.

Antes de anunciar, intermediar, ofrecer o ejecutar remesas, verifica con asesoría jurídica especializada los requisitos y autorizaciones aplicables en Cuba y en cada país desde el que se captarían clientes, así como las normas sobre servicios financieros, pagos, sanciones y protección de datos. No añadas tarifas, promesas de entrega o métodos de pago hasta que estén legalmente verificados.

El formulario no guarda datos en esta web; prepara un mensaje que el visitante puede revisar y enviar por WhatsApp. No solicites contraseñas, datos bancarios ni documentos de identidad mediante el formulario. Añade una política de privacidad revisada legalmente antes de realizar campañas o recoger datos personales de forma sistemática.
